## TechBook E-Commerce Microservices

Spring Boot 3 + Java 21 microservices architecture with:
- Eureka service discovery
- Spring Cloud Gateway
- JWT authentication
- Dockerized local setup

### Tech Stack
- Java 21
- Spring Boot 3
- Spring Cloud
- Docker & Docker Compose

### Run locally (Docker)
```bash
mvn clean package -DskipTests
docker compose up --build
